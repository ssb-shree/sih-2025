# SIH 2025 Project

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/ssb-shree/sih-2025
cd sih-2025
```

# Install Bun globally if not already installed

```bash
npm i -g bun

# Install dependencies
bun install

# Start the development server
bun run dev
```

Using Bun (Production)

````bash
# Install Bun globally if not already installed
npm i -g bun

# Build the project
bun run build

# Start the production server
bun run start```
````
